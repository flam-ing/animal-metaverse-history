# 데이팅 심 캐릭터 초상화 생성 프롬프트

## 파일 이름 규칙

게임은 이 폴더에서 다음 형식의 PNG 초상화를 자동 로드합니다:

```
<id>_<mood>.png
```

**mood 값**: `normal`, `happy`, `shy` (각 캐릭터별 3가지 표정 = 총 18개 파일)

**권장 사양**:
- 해상도: 800×1000 픽셀
- 배경: 투명 (PNG)
- 구도: 허리 위쪽 (waist-up), 정면 향
- 선화 품질: 깔끔한 라인아트

**중요**: 모든 18개 이미지는 **동일한 일관된 아트 스타일**로 통일되어야 합니다.

## 공통 스타일 프리픽스

모든 프롬프트 맨 앞에 다음을 붙여 사용하세요:

```
soft pastel anime visual-novel character bust portrait, clean lineart, cute anthropomorphic animal person, transparent background, waist-up, facing viewer, soft warm lighting, no text
```
